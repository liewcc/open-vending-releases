# Open Vending — Releases

Windows installers and auto-update files for Open Vending. No source code lives here.

## Download

Get the latest installer: https://github.com/liewcc/open-vending-releases/releases/latest

Run `Open-Vending-Setup-x.y.z.exe`. It installs per user and needs no admin rights.

## Updates

The installed app checks this repo for new versions and updates itself.
